# 怪我タブ 実装計画

> この計画は「今の最善の方針」であり、実装中に問題や改善案が出たら臨機応変に変更する。

## 概要

怪我の記録を専用タブで閲覧・管理できるようにする。  
現状は履歴タブの中に怪我情報が埋もれており、活用できていない。

## UI構造

- ナビバーに「怪我」タブを追加（記録 / 履歴 / **怪我** / 分析 / 設定）
- 怪我タブ内に「日付」「部位」のサブタブ

### 日付ビュー

日付カードが新しい順に並ぶ。カードを展開すると部位でグループ化されたセット記録が表示される。

```
2026/05/28
  右肩
    懸垂        メイン①  違和感
    ベントオーバーロー  メイン②  違和感  「重すぎた」
  左膝
    スクワット  メイン③  支障あり

2026/05/15
  左膝
    スクワット  メイン①  違和感
```

### 部位ビュー

部位カードが並ぶ（部位マスターの登録順）。カードをタップすると詳細ビューへ遷移し、その部位の全怪我履歴が新しい順に表示される。

```
右肩
  2026/05/28  懸垂        メイン①  違和感
  2026/05/28  ベントオーバーロー  メイン②  違和感  「重すぎた」

左膝
  2026/05/28  スクワット  メイン③  支障あり
  2026/05/15  スクワット  メイン①  違和感
```

## フェーズ1：閲覧のみ

### GAS（api.gs）

`getInjuryHistory` アクションを追加。

- 記録シートから `injurySite` が空でない行を全件取得
- レスポンス構造（日付ビュー・部位ビュー両方に対応できるフラット配列）:
  ```json
  {
    "records": [
      {
        "date": "2026/05/28",
        "sessionId": "sid_xxx",
        "exercise": "スクワット",
        "setType": "メイン",
        "setNum": 3,
        "side": "",
        "injurySite": "左膝",
        "injuryLevel": "支障あり",
        "injuryMemo": "痛みあり"
      }
    ]
  }
  ```
- フロント側で日付ビュー・部位ビュー用に整形する

### フロントエンド（index.html / app.js / style.css）

- ナビバーに怪我タブを追加
- 怪我タブHTML（日付ビュー・部位ビューのサブタブ）
- `loadInjuryHistory()` でAPI取得・`S` にキャッシュ
- `renderInjuryDate()` / `renderInjurySite()` の描画関数
- 部位ビューは履歴タブ種目ビューと同じ2段階構造（一覧→詳細）
- 「もっと見る」は記録数次第で要否判断（実装時に検討）

## フェーズ2：編集機能の追加（閲覧完成後に検討）

### 方針（現時点での想定）

- 各セット行に「編集」ボタンを追加
- タップすると**怪我専用の軽量モーダル**が開く（部位・レベル・メモのみ）
- 保存は新規 GAS API `updateInjury` で該当セルのみ更新

### `updateInjury` API（想定）

特定セットの怪我3フィールド（`injurySite` / `injuryLevel` / `injuryMemo`）だけをスプレッドシートのセルに直接書き込む。  
`sessionId` + `exInstanceId` + `setNum` + `setType` + `side` で行を特定する。  
既存の `updateExerciseRecords`（全セット削除→再挿入）は使わない。

### フェーズ1コードへの影響

なし。編集ボタンとモーダルを追加するだけで、データ取得・表示ロジックは変更不要。
